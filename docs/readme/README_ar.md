# AXIOM

**محرّك الاستدلال الرياضي**

*واجهة MCP واحدة للحساب والاستكشاف والتحقق من النتائج الرياضية.*

**العربية** · [English](../../README.md) · [简体中文](README_zh.md) · [繁體中文](README_zh-TW.md) · [日本語](README_ja.md) · [한국어](README_ko.md) · [Türkçe](README_tr.md) · [Русский](README_ru.md) · [Tiếng Việt](README_vi.md) · [ไทย](README_th.md) · [Deutsch](README_de.md) · [Español](README_es.md) · [Français](README_fr.md) · [Português (Brasil)](README_pt-BR.md) · [العربية](README_ar.md) · [فارسی](README_fa.md) · [Italiano](README_it.md) · [Ελληνικά](README_el.md)

AXIOM بنية تحتية للرياضيات الحاسوبية موجّهة لوكلاء الذكاء الاصطناعي والباحثين والطلاب والمطوّرين. تربط أي عميل MCP بمحرّكات رياضية متخصّصة — SymPy وSciPy وSageMath وLean 4 — من خلال عقد موحّد، مع نتائج قابلة للتتبّع يكون **التحقق منها مستقلًا**.

ليست آلة حاسبة تعمل بالذكاء الاصطناعي. وليست إصدارًا آخر من Mathematica أو SageMath أو Lean. بل هي البنية التي تتيح للوكلاء استخدام جميعها من خلال واجهة واحدة.

> مستلهَمة من فلسفة [REA](https://github.com/morluto/rea): *هندسة عكسية لأي شيء* → **تحليل الرياضيات**.

## لماذا AXIOM

قد يدّعي الوكيل أنه حلّ معادلة ما. وAXIOM **يتطلّب تحقّقًا مستقلًا** قبل أن تُصدَّق أي نتيجة.

```
math solve "x^2 - 5*x + 6 = 0"
```

```text
┌─────────────────────────────────────────────────┐
│ معادلة تربيعية                                 │
│   x² - 5x + 6 = 0                               │
│                                                 │
│ الحلول                                          │
│   x = 2  أو  x = 3                              │
│                                                 │
│ المحرّك       SymPy                             │
│ التحقق        تعويض دقيق (كسور)                 │
│ الضمان        VERIFIED-SUBSTITUTION             │
│ النتيجة       كلا الجذرين يُحقّقان المعادلة     │
└─────────────────────────────────────────────────┘
```

### مستويات الضمان

لا تحمل جميع النتائج الرياضية نفس القوة المنطقية. يميّز AXIOM بوضوح بين كل مستوى:

| المستوى | المعنى |
| --- | --- |
| `exact-symbolic` | هوية رمزية مُتحقَّق منها (مثل التبسيط القياسي) |
| `verified-substitution` | حلٌّ تم التحقق منه بالتعويض مع حساب دقيق |
| `numerical-approximation` | تقريب عددي مع خطأ مُعلن |
| `formal-proof` | برهان تحقّقت منه نواة برهان (Lean 4) |
| `heuristic` | نتيجة مرجّحة، لم تُتحقَّق منها بالكامل |
| `unverified` | حساب خام، لم يُتحقق منه بعد |

تحمل كل نتيجة بيانات إثبات وصفية: `engine`، و`engine_version`، و`steps`، و`limitations`، و`reproducible_with`.

## أدوات MCP

أدوات صغيرة قابلة للتجميع:

```
math_parse        math_simplify     math_solve
math_differentiate   math_integrate  math_limit
math_evaluate      math_plot         math_prove
math_verify        math_explain      math_compare
math_explore
```

واجهة سطر الأوامر المقترحة:

```bash
math solve "x^2 - 5*x + 6 = 0"
math integrate "sin(x)^2" --variable x
math plot "sin(x)/x" --range -10:10
math prove theorem.lean --engine lean
math verify solution.json
```

## العلاقة مع MathTools Offline

كان هذا المستودع *MathTools Offline* (حزمة سطح مكتب تعمل دون اتصال لـ LaTeX وSymPy وLean). ثم أُعيدت تسميته إلى **AXIOM** وأُعيد تعريفه كبنية تحتية للرياضيات الحاسوبية موجّهة للوكلاء. المحرّكات (SymPy وLean 4) مشتركة مفهوميًا، لكن التركيز الآن على عقد MCP الموحّد والتحقق المستقل من النتائج.
