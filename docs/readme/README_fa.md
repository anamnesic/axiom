**محرّک استدلال ریاضی**

AXIOM یک زیرساخت ریاضیات محاسباتی برای عوامل هوش مصنوعی، پژوهشگران، دانشجویان و توسعه‌دهندگان است. هر کلاینت MCP را از طریق یک قرارداد واحد به موتورهای تخصصی ریاضیات — SymPy، SciPy، SageMath، Lean 4 — متصل می‌کند، با نتایج قابل ردیابی که **به‌طور مستقل تأیید شده‌اند**.

این یک ماشین‌حساب مبتنی بر هوش مصنوعی نیست. نسخه‌ای دیگر از Mathematica یا SageMath یا Lean نیست. این زیرساختی است که به عوامل امکان می‌دهد همه آن‌ها را از طریق یک رابط واحد به کار گیرند.

> الهام‌گرفته از فلسفه‌ی [REA](https://github.com/morluto/rea): *مهندسی معکوس هر چیزی* → **تجزیه و تحلیل ریاضیات**.

## چرا AXIOM

یک عامل ممکن است ادعا کند معادله‌ای را حل کرده است. AXIOM **پیش از اعتماد به هر نتیجه، تأیید مستقل را الزامی می‌کند**.

```
math solve "x^2 - 5*x + 6 = 0"
```

```text
┌─────────────────────────────────────────────────┐
│ معادله درجه‌دو                                  │
│   x² - 5x + 6 = 0                               │
│                                                 │
│ حل‌ها                                            │
│   x = 2  یا  x = 3                              │
│                                                 │
│ موتور        SymPy                              │
│ تأیید        قراردادن دقیق (کسرها)               │
│ تضمین        VERIFIED-SUBSTITUTION              │
│ نتیجه        هر دو ریشه معادله را ارضا می‌کنند   │
└─────────────────────────────────────────────────┘
```

### سطوح تضمین

هر نتیجه‌ی ریاضی همان قدرت منطقی را ندارد. AXIOM هر سطح را به‌روشنی از هم تفکیک می‌کند:

| سطح | معنا |
| --- | --- |
| `exact-symbolic` | هم‌ارزی نمادین تأییدشده (مثلاً ساده‌سازی قاعده‌مند) |
| `verified-substitution` | حلی که با اعداد دقیق و از طریق قراردادن تأیید شده است |
| `numerical-approximation` | تقریب عددی همراه با خطای اعلام‌شده |
| `formal-proof` | اثباتی که توسط هسته‌ی اثبات (Lean 4) تأیید شده است |
| `heuristic` | نتیجه‌ی محتمل، نه کاملاً تأییدشده |
| `unverified` | محاسبه‌ی خام، هنوز تأییدنشده |

هر نتیجه فراداده‌ی شواهد را حمل می‌کند: `engine`، و`engine_version`، و`steps`، و`limitations`، و`reproducible_with`.

## ابزارهای MCP

ابزارهای کوچک و قابل ترکیب:

```
math_parse        math_simplify     math_solve
math_differentiate   math_integrate  math_limit
math_evaluate      math_plot         math_prove
math_verify        math_explain      math_compare
math_explore
```

خط فرمان پیشنهادی:

```bash
math solve "x^2 - 5*x + 6 = 0"
math integrate "sin(x)^2" --variable x
math plot "sin(x)/x" --range -10:10
math prove theorem.lean --engine lean
math verify solution.json
```

این مخزن پیش‌تر *MathTools Offline* بود (یک مجموعه‌ی دسکتاپ آفلاین برای LaTeX/SymPy/Lean). نام آن به **AXIOM** تغییر یافت و به‌عنوان زیرساخت ریاضیات محاسباتی برای عوامل بازتعریف شد. موتورها (SymPy، Lean 4) از نظر مفهومی مشترک‌اند، اما تأکید اکنون بر قرارداد واحد MCP و تأیید مستقل نتایج است.
