# AXIOM

**Μαθηματική Μηχανή Συλλογισμού**

*Ένα MCP για τον μαθηματικό υπολογισμό, την εξερεύνηση και την επαλήθευση.*

Το AXIOM αποτελεί υποδομή υπολογιστικών μαθηματικών για πράκτορες τεχνητής νοημοσύνης, ερευνητές, φοιτητές και προγραμματιστές. Συνδέει οποιονδήποτε πελάτη MCP με ειδικές μαθηματικές μηχανές — SymPy, SciPy, SageMath, Lean 4 — μέσω μιας ενιαίας σύμβασης, με αποτελέσματα που μπορούν να ανιχνευτούν και είναι **ανεξάρτητα επαληθευμένα**.

Δεν είναι αριθμομηχανή με τεχνητή νοημοσύνη. Δεν είναι και άλλο ένα Mathematica, SageMath ή Lean. Είναι η υποδομή που επιτρέπει στους πράκτορες να χρησιμοποιούν όλα τα παραπάνω μέσω μιας ενιαίας διεπαφής.

> Εμπνευσμένο από τη φιλοσοφία του [REA](https://github.com/morluto/rea): *αντιστροφή μηχανική οτιδήποτε* → **ανάλυση των μαθηματικών**.

## Γιατί AXIOM

Ένας πράκτορας μπορεί να ισχυριστεί ότι έλυσε μια εξίσωση. Το AXIOM **απαιτεί ανεξάρτητη επαλήθευση** πριν εμπιστευτεί ένα αποτέλεσμα.

```
math solve "x^2 - 5*x + 6 = 0"
```

```text
┌─────────────────────────────────────────────────┐
│ Τετραγωνική εξίσωση                            │
│   x² - 5x + 6 = 0                               │
│                                                 │
│ Λύσεις                                          │
│   x = 2  ή  x = 3                               │
│                                                 │
│ Μηχανή        SymPy                             │
│ Επαλήθευση    Ακριβής τοποθέτηση (κλάσματα)     │
│ Εγγύηση       VERIFIED-SUBSTITUTION             │
│ Αποτέλεσμα   Και οι δύο ρίζες ικανοποιούν την   │
│              εξίσωση                            │
└─────────────────────────────────────────────────┘
```

### Επίπεδα εγγύησης

Δεν φέρουν όλα τα μαθηματικά αποτελέσματα την ίδια λογική ισχύ. Το AXIOM διακρίνει ρητά κάθε επίπεδο:

| Επίπεδο | Σημασία |
| --- | --- |
| `exact-symbolic` | Επαληθευμένη συμβολική ταυτότητα (π.χ. κανονικοποίηση μέσω απλοποίησης) |
| `verified-substitution` | Λύση που επικυρώθηκε με αντικατάσταση, με ακριβή αριθμητική |
| `numerical-approximation` | Αριθμητική προσέγγιση με δηλωμένο σφάλμα |
| `formal-proof` | Απόδειξη που επαληθεύτηκε από πυρήνα αποδείξεων (Lean 4) |
| `heuristic` | Πιθανό αποτέλεσμα, όχι πλήρως επαληθευμένο |
| `unverified` | Ακατέργαστος υπολογισμός, μη επαληθευμένο ακόμη |

Κάθε αποτέλεσμα φέρει μεταδεδομένα τεκμηρίων: `engine`, `engine_version`, `steps`, `limitations` και `reproducible_with`.

## Εργαλεία MCP

Μικρά, συνθέσιμα εργαλεία:

```
math_parse        math_simplify     math_solve
math_differentiate   math_integrate  math_limit
math_evaluate      math_plot         math_prove
math_verify        math_explain      math_compare
math_explore
```

Προτεινόμενη γραμμή εντολών:

```bash
math solve "x^2 - 5*x + 6 = 0"
math integrate "sin(x)^2" --variable x
math plot "sin(x)/x" --range -10:10
math prove theorem.lean --engine lean
math verify solution.json
```

## Σχέση με το MathTools Offline

Αυτό το αποθετήριο ήταν το *MathTools Offline* (μια επιτραπέζια σουίτα εκτός σύνδεσης για LaTeX/SymPy/Lean). Μετονομάστηκε σε **AXIOM** και επανατοποθετήθηκε ως υποδομή υπολογιστικών μαθηματικών για πράκτορες. Οι μηχανές (SymPy, Lean 4) είναι εννοιολογικά κοινές, αλλά η εστίαση βρίσκεται πλέον στην ενιαία σύμβαση MCP και στην ανεξάρτητη επαλήθευση των αποτελεσμάτων.
