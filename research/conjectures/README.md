# Conjectures & Auxiliary Hypotheses — AXIOM Research

Registry of open conjectures, auxiliary statements, and experimental hypotheses explored using AXIOM.

## Structure of a Conjecture Entry

Every conjecture file (`CONJ-####.md`) must specify:
1. **Title and Mathematical Domain** (e.g. Analytic Number Theory, Algebraic Geometry).
2. **Associated Millennium Problem / Literature Reference**.
3. **Formal Mathematical Statement**.
4. **Explicit Domain and Hypotheses**.
5. **Empirical Evidence Gathered** (numerical sample agreement, symbolic checks).
6. **Current Status**: `open` | `empirically-supported` | `refuted` | `proved`.
