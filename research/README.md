# Research Directory — Chronokairo AXIOM

This directory organizes the mathematical research workflow of AXIOM across three core artifacts:

1. **`conjectures/`**: Working hypotheses, empirical conjectures, and exploratory assertions under evaluation.
2. **`lemmas/`**: Proven mathematical lemmas and Lean 4 formal proofs verified by the Lean kernel and Mathlib.
3. **`counterexamples/`**: Refuted mathematical statements, adversarial boundary cases, and concrete counterexamples discovered or verified by the engine.

## Scientific Methodology

All items in this directory must trace back to:
- A specific problem or domain context.
- Explicit hypotheses and domain constraints.
- An AXIOM `MathResult` with verifiable guarantee (`exact-symbolic`, `formal-proof`, or `unverified`).
- Full reproducibility instructions.
